# GAME MAKERS: The $2 Million Race
## Manufacturing & Print Specification v0.1

STATUS: Living engineering document — provisional until gameplay/component counts are locked.

This specification must develop alongside the game so design choices do not create an unnecessarily expensive, heavy or difficult-to-manufacture product.

# 1. Retail Product Target

Working retail box target:
- Exterior: approximately 300 x 300 x 70 mm
- Construction: rigid telescoping lid/base game box
- Preferred packed mass: under 2.3 kg
- Stretch goal packed mass: under 2.0 kg
- Player count: 2–4
- Target play time: 120–180 min

Final dimensions to be optimised after component nesting/insert design.

# 2. Main Game Board — Provisional

Working open size: 840 x 560 mm maximum.

Manufacturing direction:
- folding mounted board
- approximately 1.5–2.0 mm greyboard core
- printed art paper wrap
- matte protective finish preferred
- folds engineered to fit box with adequate clearance

Need to determine whether 6-panel or alternative fold gives best flatness/box fit.

# 3. Company Boards

Quantity: 4.
Working finished size: approximately 297 x 210 mm each.

Options to quote/test:
A. 1.5–2.0 mm mounted board.
B. 1.0–1.5 mm punchboard-style board.
C. heavy card for lower-cost edition.

Mounted board preferred if weight/cost permits because tracks carry multiple markers.

# 4. Cards

Current design count: 124+ and subject to change.

Preferred standardisation: minimise number of different card sizes.

Working main card size:
- 63 x 88 mm poker size
- rounded corners approximately R3 mm
- 300–330 gsm black-core or equivalent game-card stock
- full-colour CMYK both sides
- matte varnish/finish

Potential small/reference cards only if component engineering proves useful.

Decks currently include:
- Concepts
- Forecast/Business Conditions
- Licences
- Factories
- Market Outlook
- Opportunities/Staff/Retail

Final count and collation list required before quotation lock.

# 5. Action Tiles

Quantity: 24 (6 x 4 players).

Working size: 35–40 mm square or approximately 40 x 30 mm rectangular.
Material: 1.5–2.0 mm punchboard.
Full-colour both sides.
Rounded corners preferred if die layout permits.

# 6. Punchboard Tokens

Likely punchboard components:
- Cost of Sales tiles
- Bestseller
- Award
- Market Leader
- Sold Out
- possibly price/quality/life-cycle markers
- money/overflow markers if needed

Working board thickness: 1.5–2.0 mm.

Target token minimum practical dimension: generally 15 mm+ for handling/readability.

All punch components require 3 mm bleed in artwork unless manufacturer's template specifies otherwise.

# 7. Wooden Components

Working requirement:
- approximately 80 Stock Cubes
- order/shipping markers
- player tracking markers

Stock Cube working size: 10 mm cube.

Four strongly differentiated player colours. Colour must not be the sole identifier where components can be confused; symbols/shapes should support accessibility where practical.

Wood preferred over plastic for standard cubes unless quote/weight/availability indicates otherwise.

# 8. Track Markers

Need markers for:
- Cash
- Profit
- Reputation
- Website Level
- Appeal
- Quality
- Price
- Life Cycle

Engineering objective: reduce total unique moulded/wooden pieces by using multipurpose cubes/discs where this does not damage usability.

# 9. Rulebook

Working finished size: 210 x 210 mm or A4-derived size depending box nesting.

Target: 16–28 pages after layout.
- full-colour
- approximately 115–150 gsm coated/uncoated text stock
- saddle stitched if page count permits
- matte finish preferred for readability

Final rules must include diagrams, setup, quarter sequence, examples and Annual Accounts example.

# 10. Player Aids

Quantity: 4.
Double-sided.
Working size: A5 or approximately 148 x 210 mm.

Material options:
- 300–350 gsm card with protective varnish
- thin mounted board only if required

Should contain all frequently used tables so players rarely open rulebook.

# 11. Insert

Insert must hold components after punching and bagging, not merely factory-new components.

Options:
- formed pulp
- vacuum-formed PET/PS subject to sustainability/cost
- cardboard insert

Preferred engineering goals:
- card wells suitable for sleeved-card tolerance if feasible without enlarging box excessively
- separate token/cube areas
- rulebook/boards sit flat
- minimal component movement in vertical storage

# 12. Box

Working exterior: 300 x 300 x 70 mm.

Direction:
- rigid greyboard lid/base
- full-colour printed wrap
- matte lamination or robust matte varnish
- lid lift clearance to be manufacturer-tested

Box sides must reserve space for:
- title/logo
- player count
- age guidance
- play time
- publisher/manufacturer information
- barcode
- legal/compliance marks as required
- country of origin
- batch/lot coding location where required

# 13. Print Files

Final production artwork expected:
- CMYK
- 300 dpi raster assets at placed size
- vector text/logos where possible
- fonts outlined/embedded according to manufacturer requirement
- manufacturer dielines kept on non-print production layer
- bleed normally 3 mm unless template says otherwise
- safe zone normally at least 3–5 mm inside cut/fold, increased around folds
- rich black specifications to follow printer profile; small text should use appropriate single black where required

Do not finalise profiles until manufacturer supplies print requirements.

# 14. Colour & Accessibility

Genre coding must use colour + icon + text.

Player components must be distinguishable for common colour-vision deficiencies.

Final proofing should include:
- colour-blind simulation
- minimum text size review
- contrast review
- icon recognition test

# 15. Packed Weight Engineering

Preferred finished retail unit: <2.3 kg.
Stretch goal: <2.0 kg.

Weight budget must later be allocated across:
- box
- board
- company boards
- cards
- punchboard
- wooden components
- insert
- rulebook/aids
- bags/wrap

If weight exceeds target, reduce component mass/board size before accepting a larger/heavier box.

# 16. Shipping Carton

Not yet locked.

Manufacturer quotation must state recommended units/master carton and provide:
- carton external dimensions
- gross weight
- net weight
- units/carton
- carton board specification
- pallet quantity assumptions

Target gross carton weight should remain practical for fulfilment handling.

# 17. Packaging

Quote options:
- shrink wrap
- paper seals / tamper labels
- alternative plastic-reduction packaging

Internal components to be bagged or boxed appropriately.

# 18. Quality Control

Before mass production require:
1. digital/prepress proofs
2. physical component samples where appropriate
3. full pre-production copy
4. approved golden sample
5. mass-production QC against golden sample

QC checklist to cover:
- component counts
- colour consistency
- cutting registration
- card collation
- board warping/flatness
- punch quality
- box fit
- insert fit
- wooden piece dimensions/finish
- missing/damaged parts

AQL/inspection standard to be agreed with supplier/third-party inspector before PO.

# 19. Compliance

Final compliance plan depends on markets, age grading, component design and manufacturing country.

Before manufacture obtain specialist/manufacturer confirmation for all applicable requirements in intended markets, potentially including UK, EU and USA product/toy/game safety, chemical/material restrictions, labelling, traceability and testing.

No compliance mark should be printed until applicability and supporting documentation/testing are confirmed.

# 20. Transit Testing

Production package should be assessed for:
- retail box compression
- corner/edge damage
- master-carton handling
- drop/transit performance
- component movement inside insert

Final test protocol to be agreed based on distribution method.

# 21. Spare Components

Quote a small factory overage/spares allowance for replacement service.

Working target: approximately 1–2% spare generic components/cards where practical, adjusted for production method and supplier MOQ.

# 22. Manufacturer RFQ Package — Eventually Required

The final RFQ will contain:
- complete BOM/component manifest
- quantities per game
- dimensions
- materials
- print/finish
- dielines
- reference renders/photos
- packaging sequence
- packed target dimensions/weight
- production quantity quote tiers (e.g. 1K/2K/3K/5K/10K)
- requested tooling charges separated
- sample/proof charges
- testing charges
- EXW/FOB pricing as appropriate
- production lead time
- carton/pallet data

# 23. Cost Engineering

For every component revision track:
- gameplay value
- unit manufacturing cost impact
- packed weight impact
- box-volume impact
- assembly labour impact
- freight impact

No component should survive merely because it looks impressive if it adds little gameplay value.
